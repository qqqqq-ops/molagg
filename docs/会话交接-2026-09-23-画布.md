## 一、本会话做完了什么

### 1. 删掉循环节点，改成生成器上的「生成数量」
用户质疑「10 张图连到视频生成器点一次生成不是应该出一条吗」——是对的。循环节点让「出几条」取决于怎么连线，

「生成数量」按模型给范围：图片 1–4、视频 1–2、Midjourney 只有 1（它一个任务本来就返回四宫格）。

### 2. 画布中英双语（中文默认）

用户：「画布背景不能是黑色 很不明显」。根因是画布底 `#090b0c` 和卡片 `#0f1213` 只差几档亮度。

### 4. 左侧「助手」（新增 `canvas-v2/assistant/`）

对照参考站的 `rail.assistant`「AI 助手 — 对话式自动操作画布 (建/连/改节点 + 生成)」和 `inspector`「检查器」。

## 二、必须守住的约束（改代码前先看这条）

1. **红线（历次会话都在）**：只开放接口、不索取用户 API key（用户原话「用户自己去填 key 和 url」）；
   不使用用户给过的参考站凭据；查 SQLite 只读非密列。
2. **视觉验证全部由用户做**——本地没有浏览器工具（用户已拒装 Chrome 扩展），不要替他下「效果不错」的结论。
3. **助手不许点生成。** 动作表里没有「运行」这个类型，模型回了也会被当非法动作丢掉（`test-as.cjs` 有断言盯着）。
   跑一次是真金白银的上游调用，那一下必须由人按。界面上也明写了这句。**下个会话别为了"方便"把它加回去。**
4. **模型不支持的素材不冲掉。** 用户原话：「用户已上传素材如果选择的模型不支持不要冲掉 不然一直选素材很烦的
   万一人家有十张图呢 如果模型不支持此素材 在点生成的时候直接报错该模型不支持此素材」。
   —— 上面第 7 项「自动换模型」要注意别跟这条打架：可以提示、可以建议，别悄悄替用户改。
5. **换模型时把画幅/分辨率/时长重置成新模型的默认值**（用户拍板，保持现状）。
6. **讲人话。** 用户原话「其实我听不懂」。汇报时说用户能感知到的表现，不要用工程术语。
7. **代码风格：无分号、单引号、print-width 120、trailing comma。仓库里没有 `.prettierrc`**，
   跑裸的 `npx prettier --write` 会把文件改成分号 + 双引号。要跑就带上
   `--no-semi --single-quote --print-width 120 --trailing-comma all`。
8. **界面文字 ≠ 提示词内容。** `promptFragment` / `snippet.content` / 系统提示词是**发给模型的**，
   永远写英文，不进 i18n；只有给人看的名字跟语言走。`test-i18n.cjs` 有断言。
9. **请求参数的拼装不能盲搭。** 各家参数名完全不同（GPT Image 用 `size`、豆包没有比例参数、MJ 要 `botType`、
   视频侧是 `ratio` 不是 `aspectRatio`）。必须复用 `home/landingGenerate.ts` 的 `buildLandingParameters`。
   这条是踩过坑写下来的。

### B. 画布视频打不开（打叉播放键）— 已修
- 根因：`ContentNodes.tsx` 视频元素带 `crossOrigin="anonymous"`（为「截帧」读画面进 canvas），但结果地址是绝对 `http://localhost:3000/uploads/...`，画布开在 3001 = 跨源，后端 `/uploads` **不返回 CORS 头** → 浏览器拦掉视频。
- 修：`ContentNodes.tsx` 加 `sameOriginUpload()`，把图片/视频/音频的 `src` 从绝对 `http://host:3000/uploads/...` 改成**相对 `/uploads/...`**（跟当前站点走 = 同源，3001 代理到后端）。视频能放 + 截帧保住（同源 canvas 不 taint）。`blob:`/`data:` 本地预览不受影响。
- 注意：库里存的仍是绝对地址；这是**渲染时改写**。别的页面（任务队列等）若也从别的 origin 访问，可能有同样的绝对地址隐患，暂只修了画布。
