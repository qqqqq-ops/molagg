## 2. 验证纪律（必须照做）

**Tailwind 任意值会静默失效。** 每次改完对着编译产物核对：

```bash
cd frontend && npm run build
grep -oE 'max-w-\[[0-9]+px\]' dist/assets/*.css | sort -u
python3 -c "
import glob
for f in glob.glob('dist/assets/index-*.js'):
    s=open(f,encoding='utf-8').read()
    print(s.count('你要确认的字符串'))
"
```

已知两类失效：

1. `@tailwindcss/aspect-ratio` 插件**顶掉核心 `aspect-*`** —— `aspect-square` 不编译，登录页球体高度归零、整个环绕塌掉。用内联 `style={{ aspectRatio: '1 / 1' }}`。
2. 透明度修饰符**只支持 5 的倍数** —— `bg-white/8`、`border-white/12`、`bg-white/18` 全部被静默丢弃。

另外：**所有视觉验证都由用户做**，我全程没有浏览器工具（用户已拒装 Chrome 扩展，本会话不要再提）。不要声称"已确认页面效果"。
